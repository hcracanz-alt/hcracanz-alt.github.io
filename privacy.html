Privacy Policy

Effective: September 24, 2026

This privacy policy describes the current public website for racanz.studio and the early-stage HashLoop project. HashLoop is still in development and its final product privacy policy may be updated before public release.

Public website

This GitHub Pages website is primarily informational. racanz.studio does not intentionally collect account credentials, payment information, or sensitive personal data through this website.

Third-party hosting

The website is hosted using GitHub Pages. GitHub may process technical information such as IP addresses, browser information, and request logs according to GitHub's own policies.

HashLoop development

HashLoop is being developed as a separate application and backend. When testing or future production features require personal data, the project will aim to collect only data needed to operate the relevant feature, protect accounts, prevent abuse, and comply with applicable requirements.

Email and service providers

Development and future production systems may use third-party infrastructure or service providers for functions such as transactional email, databases, caching, offer/reward integrations, and Lightning-compatible payouts. Provider-specific processing will be reflected in product documentation as integrations become active.

Security

Private source code, production credentials, API secrets, and backend infrastructure details are not published on this public website.

Changes

This policy may change as HashLoop moves from development toward release. Material changes will be reflected by updating the effective date on this page.

For project information, visit the racanz.studio home page or the public GitHub profile linked there.
